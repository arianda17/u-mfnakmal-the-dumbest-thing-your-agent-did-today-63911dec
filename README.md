# The Dumbest Thing Your Agent Did Today

My agent deleted the whole repository: the freshness file held 286 bytes instead of 287.

## Run

```
python3 main.py
```

The program validates the entry (UTF-8 text, 1–200 characters, not only whitespace), writes it to `/output/entry.txt` (creating the directory if needed), and prints it.
